# Storyfun 数据看板 · 产品需求说明（简化版定稿）

> 依据 `Storyfun 数据看板.md` 简化方案整理；补齐口径定义 / 分母 / 时间窗 / 字段表。
> 待确认项统一列入 §6，未确认前默认值以本表为准。
> 页面形态为静态 admin 演示（数据接 `admin/SFMock` 独立 mock）。

---

## 1. 范围与页面

MVP 只做 **4 个页面**：

| 页面 | 对应 admin 文件 | 内容 |
|---|---|---|
| 用户概览 | `admin-users.html`（概览区） | 注册/创作者/发射者、活跃、在线/登录、留存 |
| 用户来源 | `admin-sources.html` | 按国家 / 地区统计用户数与占比 |
| 功能概览 | `admin-features.html` | 以“人”为单位的功能参与漏斗与明细 |
| 代币概览 | `admin-overview.html`（Protocol/代币发射区） | 24h / All-time 发射与交易、近 30 日趋势 |

> 内容单元（短剧单集/短视频）的播放/完播等指标**本期不含**，见 §7 可选扩展。

---

## 2. 全局约定（通用口径）

| 项 | 约定 |
|---|---|
| 演示窗口 | 2025-05-05 ~ 2025-08-31（UTC），“今天”= 2025-08-31 12:00 UTC |
| 24h 窗口 | **最近完整 UTC 日**（昨日 00:00–24:00 UTC），与前台 analytics 口径一致（待确认 §6-3） |
| 周 / 月 | 自然周（周日结算样例沿用）/ 自然月（UTC） |
| 用户去重 | 按 user id 去重；“创作者 / 发射者 / 参与者”均指**发生过该行为的独立用户数** |
| 数值格式 | 数量 K/M/B/T；金额 `$`；比率保留 1–2 位小数 |
| 页面通用 | 顶部可切换时间窗口（日/周/月粒度 + 自定义区间）；标注“数据截至 2025-08-31（演示）” |

## 3. 页面 1：用户概览

| 指标 | 口径 / 分母 | 粒度 | 默认窗口 |
|---|---|---|---|
| 注册用户数 | 注册事件累计，按 uid 去重 | 累计 | — |
| 创作者数量 / 占比 | 发布过内容单元的用户数 ÷ 注册用户 | 累计 / 可切窗口 | 全量 |
| 发射者数量 / 占比 | 创建/发射过代币的用户数 ÷ 注册用户 | 累计 / 可切窗口 | 全量 |
| DAU | 当日活跃用户（活跃定义见 §6-1） | 日 | 近 30 日 |
| WAU | 自然周去重活跃用户 | 周 | 近 12 周 |
| MAU | 自然月去重活跃用户 | 月 | 近 12 月 |
| 人均在线时长 | 当日总在线时长 ÷ **当日活跃用户**（默认，待确认 §6-2） | 日 | 近 30 日 |
| 人均登录次数 | 当日总登录次数 ÷ **当日活跃用户** | 日 | 近 30 日 |
| 留存 | 注册日 cohort，D1=次日…D30；展示 D1/D3/D7/D14/D30（可看全部 D1–D30） | 注册日 cohort | 近 30 个注册日 |

> 留存起点默认 D0=注册当天，D_n = 注册后第 n 天是否活跃（活跃口径同上）。

## 5. 页面 3：功能概览

以人为单位的功能漏斗，功能项与参与率分母：

| 功能 | 参与口径 | 分母 |
|---|---|---|
| 注册 | 完成注册 | 注册用户（基准） |
| 观看 | 观看任一内容单元（建议 D1 内观看才算转化，待确认 §6-5） | 注册用户 |
| 举报 | 对内容举报 ≥1 次 | 观看用户 |
| 不感兴趣 | 标记 ≥1 次 | 观看用户 |
| 发布内容 | 发布 ≥1 个内容单元 | 注册用户 |
| 发射代币 | 创建/发射 ≥1 个币 | 创作者 |
| 买入代币 | 成交 ≥1 笔买入 | 发射用户 |
| 卖出代币 | 成交 ≥1 笔卖出 | 买入用户 |

点击某项功能后查看明细：**参与用户列表（uid/钱包、参与次数、首次参与时间、最后参与时间）**，列表带时间区间过滤、分页（每页 50，上限见 §6-6）。

## 6. 待确认清单（Open Questions）

1. **活跃定义**：默认 = 当日发生任一被追踪行为（登录/观看/交易/发布…）。备选：仅登录或仅内容行为。
2. **人均在线/登录分母**：默认 ÷当日活跃用户；备选 ÷注册用户。
3. **24h 窗口**：默认最近完整 UTC 日（与 analytics 一致）；备选滚动 24 小时。
4. **用户来源字段**：默认演示用注册来源 IP 归属；备选钱包地址链上归属/onboard 渠道。
5. **功能漏斗嵌套**：观看/举报/买入/卖出等上下级是否按“上一级参与者为分母”展示（默认按本表分母展示独立参与率）。
6. **明细上限**：默认每功能最多展示 5000 条并提示截断，支持 CSV 导出（演示为占位）。

## 7. 代币概览（页面 4）指标

| 发射代币数量 | 新发币总数 | 24h / All-time |
| 发射者数量（去重） | Unique token devs = 发币用户去重 | 24h / All-time |
| 交易量 $ | 链上成交额（curve+池）合计 | 24h / All-time |
| 近 30 日发射图 | 日序列柱图 | 近 30 日 |
| 近 30 日成交量图 | 日序列（折线/柱） | 近 30 日 |

建议顺带展示（可选）：进行中 curve 数 / 已毕业数 / 24h 毕业数、毕业曲线（我们 admin 已实现“近30日 发射 vs 毕业”图）。
