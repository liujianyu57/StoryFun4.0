## 1. 页面定位与用户故事

- **定位**：一站式“把一个叙事/作品发射成链上代币”的创建入口，创建后进入发射曲线，筹满即毕业上池。
- **用户故事**
  - 作为创作者，我可以把一部短剧/AI 叙事作为故事的关联来源，并**独立上传一张必填的币图**作为代币门面。
  - 作为创作者，我可以选择费用分配方式（分给持有者 / 归我指定钱包），并设置创作者税与风控名单。
  - 作为评审/运营，我希望创建前的每个参数都有明确含义与边界，且关键风险（狙击、税率、毕业）被清晰提示。

---

## 2. 主流程与信息架构

```
进入页面
 ├─ ① 基础信息（名称/代号/一句话介绍）
 ├─ ② 关联叙事（可选）：绑定短剧/AI 叙事；选中后默认带入其封面为币图
 ├─ ②b 币图（必填）：可上传/更换，覆盖叙事默认封面
 ├─ ③ 社会化资料（可选）：X / Telegram
 ├─ ④ 发行参数
 │    ├─ 配对资产（计价资产）→ 展示该资产的毕业阈值
 │    ├─ 开发者预买（可选）
 │    └─ 高级设置
 │         ├─ 费用分配（分给持有者 / 指定钱包）
 │         ├─ 创作者税（0–10%）
 │         └─ 狙击税豁免名单
 ├─ ⑤ 右侧/底部费用摘要（实时）
 └─ 创建 → 成功页（查看市场 / 查看我的币）
```

## 3. 字段字典

### 3.1 基础信息

| 字段 | 含义 | 必填 | 输入/校验 | 默认 | 联动/说明 |
|---|---|---|---|---|---|
| 名称 Name | 代币对外名称 | 是 | 文本 | 空 | 与代号一起做唯一性/展示 |
| 代号 Symbol | 交易代号 | 是 | 2–20 位字母/数字（大写） | 空 | **平台内唯一**，重复即报错 |
| 一句话介绍 Tagline | 简述项目 | 否 | 文本 | 空 | 上架后在详情页展示 |

### 3.2a 关联叙事（选填）

| 控件 | 含义 | 规则 |
|---|---|---|
| 关联叙事 | 绑定一部已有短剧/AI 叙事，作为该币的故事来源 | 独立选填；不选也可创建 |
| 封面带入 | 选中叙事后，**币图默认带入其封面/视频封面** | 为默认值，用户可继续上传覆盖 |
| 叙事视频 | 若叙事带视频，一并作为币的叙事视频 | 与币图互不影响 |

### 3.2b 币图（必填）

| 控件 | 含义 | 规则 |
|---|---|---|
| 币图 | 代币主视觉（列表/详情/分享卡封面） | **必填** |
| 默认来源 | 关联叙事后自动带入叙事封面 | 未上传时即以此满足“必填” |
| 上传/更换 | 自定义上传覆盖默认封面 | 上传状态：未选 → 上传中 → 已就绪；预览卡同步 |
| 校验 | 未关联叙事且未上传图 → 不允许创建 | 提交前提示上传币图 |

> 设计意图：叙事是“故事上下文”（可选增强），币图是**每币必备的门面**（必填），二者解耦。
> 为降低填写成本：关联叙事时封面自动带入，用户无需重复上传。

### 3.3 社交资料（可选）

| 字段 | 含义 |
|---|---|
| X 链接 | 项目 X 账号（展示于详情页社区入口） |
| Telegram | 社群链接（同上） |

### 3.4 配对资产（计价资产）

- **含义**：本币的“计价/结算货币”。整条发行曲线、价格、费用、毕业阈值都以它计。
- **交互**：自绘下拉（非原生 select），分组展示「主资产 / 加密资产 / 股票代币」。
- **选中后联动**
  1. 立即开始“读取毕业阈值”，完成后显示形如 `曲线募满 X {资产} 后自动毕业`；
  2. 底部摘要的「配对资产」「应付发行费」「发射窗口」同步更新；
  3. 开发者预买行的币种、可用余额、Max、水龙头跟随所选资产切换（切换后清空已填预买量，避免单位错配）。

### 3.5 开发者预买（可选，团队自购）

| 概念 | 说明 |
|---|---|
| 数量 | 创建者在发射交易中一并买入的币量（单位为配对资产） |
| 可用余额 | 该配对资产的可用额 |
| Max | 一键填入全部可用余额 |
| 水龙头 | 测试/演示环境的补额入口（生产不出现；真网场景为真实余额） |
| 校验 | 数量≥0 且 ≤ 余额；不足时阻止创建并提示 |

> 业务语义：相当于“团队首笔建仓”，随发射交易原子完成，创建后计入创建者持仓，可正常后续交易。

### 3.6 高级设置

#### (a) 费用分配（二选一单选卡）
| 选项 | 语义 | 界面联动 |
|---|---|---|
| 分给持有者（Holder fee sharing） | 创作者费归该币持有者，通过费分配器分发 | 隐藏“收款钱包”输入 |
| 归我（指定钱包） | 创作者费打给指定收款地址 | 显示“收款钱包”输入 |

#### (b) 收款钱包（B 选项时可见）
- 含义：创作者费收款地址（可后续在币详情 Transfer 更改，只影响未来费用）。
- 校验：合法链上地址；留空时回退为创建者连接钱包。

#### (c) 创作者税 Creator tax
- 含义：在交易费之上，按成交额加收的**额外费率**归创建者（或按 (a) 归持有者）。
- 输入：0–10%，支持小数；失焦/回车钳制，非法输入回退并提示。
- 展示：与费用分配路由联动显示在摘要。

#### (d) 狙击税豁免名单（Snipe tax exemptions）
- 背景：发行首秒内的买入会触发高额狙击税（99%），数秒内衰减至 0 —— 用于拦截抢跑机器人。
- 含义：创建者声明**团队开局使用/不应被狙击惩罚的钱包地址白名单**。
- 交互：输入地址 → 添加 → 胶囊列表；可移除。
- 规则：上限 32 个（链上工厂限制）；重复地址去重；非法地址拒绝并提示。
- 提示文案常驻说明狙击窗口与“请声明团队钱包”的要求。

## 4. 摘要区（实时费用预估）

- 展示：`{配对} 配对 · 应付发行费 {ETH}`、创作者费路由与税率、狙击窗口提示、预计毕业阈值。
- 任何发行参数变化（配对资产 / 预买 / 税 / 路由）→ 摘要即时刷新，形成“所见即所得”。

## 5. 业务规则摘要

1. **创建即上架**：创建后立即进入发行曲线，首笔买入从第一块开始，无人工审核期（平台按合规要求另行披露）。
2. **毕业**：曲线募集达到该配对资产阈值后自动上池，流动性永久锁定。
3. **费结构**：交易费（协议基础费率）+ 可选创作者税；费路由按费用分配选择：持有者分配器 or 指定钱包。
4. **狙击税**：仅发行窗口极早期生效并快速衰减；豁免名单内的地址不受惩罚。
5. **唯一性**：代号全平台唯一，防止仿冒；名称建议唯一（规则可评审）。
6. **不可变性提示**：创建后供应、定价曲线等核心参数不可改（费用路由、收款地址可在限定的安全范围内变更）。

## 6. 异常与边界（评审重点）

| 场景 | 预期行为 |
|---|---|
| 代号重复 / 含非法字符 | 行内报错、阻止创建 |
| 未关联叙事且未上传币图 | 阻止创建并提示“请上传币图”（关联叙事可带入封面，无需重复上传） |
| 预买金额超余额 / 为负 | 阻止并提示可用余额与 Max |
| 税率非法（>10 / 负数 / 非数字） | 失焦钳制；无法提交非法值 |
| 豁免地址非法 / 超 32 个 / 重复 | 拒绝添加 / 去重 / 满额禁用 |
| 收款钱包非法地址 | 校验并提示 |
| 中途切换配对资产 | 清空预买金额、重置余额行与毕业阈值展示，防单位错配 |
| 创建进行中 | 按钮置灰“创建中”，防重复提交 |
| 成功 | 进入成功页：查看市场 / 查看我的币 |

## 7. 评审待决问题（Open Questions）

1. 名称是否也需要全局唯一，还是允许同名不同代号？
2. 费用分配“分给持有者”切换后是否**允许再切回**（平台侧为防操纵可能单向锁定）——产品上建议在创建时提示不可逆性。
3. 狙击税豁免名单是否公开可见（透明 vs 隐私）？
4. 开发者预买是否需要披露在币详情（链上可见即可，还是页面另标“团队持仓”）？
5. 收款钱包变更是否需要冷却期或时间锁？
6. 社交资料为空是否影响上架或仅影响详情展示？

## 8. 验收清单（创建页）

- [ ] 基础信息校验（必填、代号规则、唯一性）有效
- [ ] 关联叙事为独立选填；选中后币图自动带入其封面
- [ ] 币图必填校验：无叙事且未传图时阻止创建；上传状态文案正确，可覆盖默认封面
- [ ] 配对资产下拉分组正确；选中后毕业阈值“读取→显示”流程完整
- [ ] 摘要区随任意参数变化实时更新且单位正确
- [ ] 高级设置：路由单选联动钱包输入显隐；税率钳制；豁免名单增删与 32 上限
- [ ] 预买：余额/Max/单位随资产切换、超余额拦截
- [ ] 创建防重复提交；成功跳转与返回入口可用
- [ ] 错误提示（中/英文态）均可达且不残留
